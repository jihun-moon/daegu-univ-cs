# W02: table 태그로 시간표 만들기

과제로 받은 시간표 이미지를 보고 같은 구조를 `<table>`로 만드는 실습입니다.
에브리타임 시간표 화면을 참고해서 색과 여백을 맞췄습니다.

## 구현한 것

- 페이지 위쪽에 과제 정보(Report 2장, 이름, 학번)를 넣고, 그 아래 [대구대학교 LMS](https://lms.daegu.ac.kr/ilos/main/main_form.acl)로 가는 버튼을 `<a>`로 만들었습니다. 버튼 색은 대구대 메인 색상인 `#004a9e`로 잡았습니다.
- `<thead>`에 월~금, `<tbody>`에 9시부터 4시까지 8행을 두고 `<table>`, `<tr>`, `<th>`, `<td>`로 그리드를 짰습니다.
- 여러 교시에 걸친 강의는 `rowspan`으로 묶었습니다. 월요일 서버시스템관리는 1시부터 4시까지라 `rowspan="4"`, 소프트웨어공학과 데이터마이닝, 웹프로그래밍은 `rowspan="2"`입니다.
- 과목마다 `.c1` ~ `.c5` 클래스를 붙여 배경색을 다르게 주고, 칸 안에 과목명과 강의실(공학7관-XXXX)을 두 줄로 넣었습니다.
- Google Fonts에서 Noto Sans KR을 불러와 본문 글꼴로 썼습니다.
- `js/script.js`에서 `.class-item` 전체에 클릭 이벤트를 걸어, 칸을 누르면 과목명과 강의실을 `alert`로 띄우게 했습니다.

## 알게 된 것

`rowspan`을 쓰면 그 아래 행에서 `<td>`를 하나 빼야 합니다.
처음에 빈 `<td>`를 그대로 두는 바람에 아래 행이 한 칸씩 오른쪽으로 밀렸습니다.
월요일 `rowspan="4"` 한 줄 때문에 아래 세 행의 `<td>` 개수가 전부 달라져서, 행마다 칸 수를 직접 세어 가며 맞췄습니다.
