# 웹 프로그래밍

대구대학교 3학년 2학기 웹 프로그래밍 수업 기록입니다.
교재가 12장 구성이라 폴더 이름도 그 순서를 따릅니다.
`lectures/`는 수업 시간에 따라 친 교재 예제이고, `labs/`는 주차별로 제출한 과제입니다.

## 폴더 구성

| 폴더 | 내용 |
| --- | --- |
| [labs](labs) | 주차별 실습 과제 (W01 ~ W12) |
| [assignments](assignments) | 교재 3장 범위를 시험 대비로 정리한 노트 |
| [lectures](lectures) | 교재 1장 ~ 12장 예제 코드 |
| [textbook_exercises](textbook_exercises) | 장별 연습문제 풀이 |

## 주차별 실습

| 주차 | 주제 | 폴더 |
| --- | --- | --- |
| W01 | 제목 태그와 DOM 제어 | [W01_basic_tags](labs/W01_basic_tags) |
| W02 | `<table>`로 시간표 만들기 | [W02_timetable](labs/W02_timetable) |
| W03 | 시맨틱 태그로 온라인 명함 만들기 | [W03_HTML-Structure-and-Forms](labs/W03_HTML-Structure-and-Forms) |
| W04 | 날짜·시간 계열 `input` 타입 자동 채우기 | [W04_Web-Forms](labs/W04_Web-Forms) |
| W06 | 색상 표현 단위 비교 | [W06](labs/W06) |
| W08 | `position: fixed`로 요소 고정하기 | [W08](labs/W08) |
| W10 | 가위바위보 게임 | [가위바위보](labs/W10/가위바위보) |
| W10 | 입력값으로 글자색 바꾸기 | [사용자 입력으로 문자 색 바꾸기](labs/W10/사용자%20입력으로%20문자%20색%20바꾸기) |
| W11 | 교재 6·7장 연습문제 풀이 페이지 | [W11](labs/W11) |
| W12 | DOM으로 할 일 목록 만들기 | [W12](labs/W12) |

W05와 W07은 폴더가 없고, W09는 폴더만 있고 파일이 비어 있습니다.
W04·W06·W08·W11·W12는 CSS와 JS를 `index.html` 안에 인라인으로 넣어서 `css/`, `js/` 폴더가 빈 채로 남아 있습니다.

## 교재 장 구성

`lectures/` 아래 폴더 번호가 교재 장 번호와 그대로 맞습니다.

| 폴더 | 장 |
| --- | --- |
| [chap_01](lectures/chap_01) | HTML5와 웹 프로그래밍 |
| [chap_02](lectures/chap_02) | HTML5로 기본 문서 만들기 |
| [chap_03](lectures/chap_03) | 문서 구조화와 웹 폼 |
| [chap_04](lectures/chap_04) | CSS3로 웹 페이지 꾸미기 |
| [chap_05](lectures/chap_05) | CSS3의 고급 기능 |
| [chap_06](lectures/chap_06) | 자바스크립트와 ES6 |
| [chap_07](lectures/chap_07) | 자바스크립트 객체 다루기 |
| [chap_08](lectures/chap_08) | 문서 객체모델 이해하기 |
| [chap_09](lectures/chap_09) | 이벤트 처리하기 |
| [chap_10](lectures/chap_10) | 브라우저 객체모델과 반응형 웹 |

각 장 폴더는 `index_NN.html`(예제 목록)과 `html/`(개별 예제)로 나뉩니다.
파일명 뒤에 `_c`가 붙은 것은 코드를 화면에 그대로 보여 주는 버전입니다.
