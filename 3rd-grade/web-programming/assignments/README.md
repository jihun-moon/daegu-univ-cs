### **[2단] HTML의 구조 (구조화 & 입력)**

#### **3️⃣ 챕터 3: 문서 구조화와 웹폼**

* **구조화 기본 태그 & 전역 속성**
    * `<div>`(블록) vs `<span>`(인라인): `<div>`는 한 줄 전체를 차지하는 큰 상자, `<span>`은 글자 일부만 감싸는 작은 상자.
    * **전역 속성**: 모든 태그에 공통으로 사용할 수 있는 속성.
        | 속성 | 설명 | 비고 |
        | :--- | :--- | :--- |
        | `id` | **고유 식별자** (페이지 내 유일해야 함) | CSS `#`, 북마크 목적 |
        | `class` | **그룹 식별자** (여러 번 중복 사용 가능) | CSS `.`, 스타일 그룹화 |
        | `title` | **툴팁** (마우스를 올리면 추가 정보 표시) | |
* **시맨틱 태그 I - 페이지 전체 구조**
    * `<div>` 대신 의미에 맞는 태그를 사용해 검색 엔진 최적화(SEO) 및 코드 가독성을 높인다.
    * `<header>`: 머리말 | `<nav>`: 메뉴 | `<main>`: 핵심 내용(1회만) | `<section>`: 주제별 구획 | `<article>`: 독립된 글 | `<aside>`: 보조 내용 | `<footer>`: 바닥글
* **시맨틱 태그 II - 세부 콘텐츠 표현**
    * `<blockquote>`: 긴 인용문 (블록). `<cite>`는 출처, `<q>`는 짧은 인용문(인라인).
    * `<figure>` & `<figcaption>`: 이미지, 코드 등을 `<figure>`로 감싸고, `<figcaption>`으로 제목이나 설명을 붙인다.
    * `<details>` & `<summary>`: 접었다 폈다 할 수 있는 상세 정보. `<summary>`가 제목 역할.
    * `<iframe>`: 다른 웹 페이지를 현재 문서 안에 삽입하는 창(인라인 프레임).
        * **주요 속성**: `src`(경로), `srcdoc`(HTML 직접삽입), `name`(프레임 이름).
    * `<time>`: 날짜/시간. | `<ruby>`: 문자 위에 주석(`<rt>`) 표시.
* **웹폼 `<form>` 확장 (⭐실기 핵심)**
    * **`<form>` 태그**: `action`(제출할 서버 URL), `method`(전송 방식 `get`/`post`) 속성 필수.
    * **폼 요소 공통 속성 (필수 암기)**
        | 속성 | 설명 |
        | :--- | :--- |
        | `name` | 서버로 전송될 때 데이터의 **이름** 역할. (⭐라디오/체크박스 그룹화) |
        | `value` | 요소의 **초기값** 또는 서버로 전송될 값. |
        | `placeholder` | 입력 예시를 보여주는 **안내 문구**. |
        | `required` | **필수 입력** 항목으로 지정. |
        | `disabled` | 요소를 **비활성화** (선택/입력/전송 모두 불가). |
        | `readonly` | **읽기 전용**으로 지정 (수정 불가). |
        | `checked` | `radio`, `checkbox`의 **기본 선택** 항목 지정. |
    * **`<label>` 사용법**: `for` 속성으로 `id`를 연결하거나(명시적), 입력 요소를 감싸서(암시적) 사용.
    * **`<input>` 타입 완전 정리**
        | type | 설명 | 주요 속성 |
        | :--- | :--- | :--- |
        | `text`, `password` | 한 줄 텍스트, 비밀번호 | `placeholder`, `maxlength` |
        | `radio`, `checkbox` | 단일 선택, 복수 선택 | `name`, `value`, `checked` |
        | `file` | 파일 첨부 | `accept` (파일 종류 지정) |
        | `date`, `number`, `range`| 날짜, 숫자, 슬라이더 | `min`, `max`, `step` |
        | `email`, `url`, `tel`| 이메일, 주소, 전화번호 (형식 검증) | `required` |
        | `submit`, `reset` | **폼 제출, 초기화 버튼** | `value` (버튼 텍스트) |
        | `hidden` | 숨겨진 데이터 | |
    * **`<button>` vs `<input type="button">` 비교**
        | 구분 | `<button>` 태그 | `<input>` 태그 |
        | :--- | :--- | :--- |
        | **내용** | **`<img>` 태그나 텍스트 등** 자유롭게 넣을 수 있음 | `value` 속성으로 **텍스트**만 표시 |
        | **기본값** | `type` 미지정 시 **`submit`**(제출)으로 동작 | `type="button"`은 아무 동작 안 함 |
    * **선택 목록: `<select>` vs `<datalist>` (O/X 대비)**
        | 구분 | `<select>` (선택 상자) | `<datalist>` (콤보 박스) |
        | :--- | :--- | :--- |
        | **특징** | **정해진 목록에서만** 선택 가능 | **직접 입력**도 가능하고, **추천 목록**도 제공 |
    * **`<textarea>`**: 여러 줄 텍스트 입력 (`rows`, `cols`로 크기 지정)
* **진행 및 수치 표현**
    | 태그 | 설명 | 예시 |
    | :--- | :--- | :--- |
    | `<progress>` | 작업의 **진행률** (0~100%) | 파일 업로드 진행률 |
    | `<meter>` | 정해진 범위 내의 **수치/비율** | 디스크 사용량 (80/100GB) |
