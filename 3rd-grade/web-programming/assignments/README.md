### **[2단] HTML의 구조 (구조화 & 입력)**

#### **3️⃣ 챕터 3: 문서 구조화와 웹폼**

  * **구조화 기본 태그 & 전역 속성**
      * `<div>` vs `<span>`: `<div>`는 블록(한 줄 전체) 단위의 논리적 영역, `<span>`은 인라인(콘텐츠 크기만큼) 단위의 작은 논리적 영역을 만든다.
      * **전역 속성**: 모든 태그에 공통으로 사용할 수 있는 속성.
        | 속성 | 설명 | 비고 |
        | :--- | :--- | :--- |
        | `id` | **고유 식별자** (페이지 내 유일해야 함) | CSS `#`, 북마크 목적 |
        | `class` | **그룹 식별자** (여러 번 중복 사용 가능) | CSS `.`, 스타일 그룹화 |
  * **시맨틱 태그 I - 페이지 전체 구조**
      * `<div>` 대신 의미에 맞는 태그를 사용해 검색 엔진 최적화(SEO) 및 코드 가독성을 높인다.
      * `<header>`: 머리말 | `<nav>`: 메뉴 | `<main>`: 핵심 내용(1회만) | `<section>`: 주제별 구획 | `<article>`: 독립된 글 | `<aside>`: 보조 내용 | `<footer>`: 바닥글
      * **시맨틱 계층 구조 예시**
        ```html
        <body>
          <header> <nav>...</nav> </header>
          <main>
            <section> <article>...</article> </section>
            <aside>...</aside>
          </main>
          <footer>...</footer>
        </body>
        ```
  * **시맨틱 태그 II - 세부 콘텐츠 표현**
      * `<blockquote>`: 긴 인용문 (블록). `<q>`는 짧은 인용문(인라인).
      * `<figure>`: 이미지, 코드 등을 감싸는 단위. `<figcaption>`으로 설명을 붙임.
        ```html
        <figure>
          <img src="photo.jpg" alt="사진">
          <figcaption>사진 설명</figcaption>
        </figure>
        ```
      * `<details>`: 접었다 폈다 할 수 있는 상세 정보. `<summary>`로 제목을 표시.
          * **코드:** `<details><summary>제목</summary>상세 내용</details>`
      * `<iframe>`: **다른 웹 페이지를 현재 문서 안에 삽입하는 창(인라인 프레임)을 만듭니다.** (서술형 대비)
        | 속성 | 설명 |
        | :--- | :--- |
        | `src` | 프레임에 표시할 문서의 경로 또는 URL |
        | `srcdoc` | `src` 대신 간단한 HTML 코드를 직접 삽입 |
        | `name` | 프레임의 고유 이름 지정 (`<a>` 태그의 `target`으로 사용) |
  * **정보 표현 태그**
      * `<time>`: 날짜(`2025-10-04`)나 시간(`19:00`) 정보에 의미 부여.
      * `<progress>`: 작업의 **진행률** 표시. (ex: 다운로드 진행 바)
      * `<meter>`: 정해진 범위 내의 **수치**(비율) 표시. (ex: 디스크 사용량 80%)
      * `<ruby>`: 동아시아 문자 위에 주석(읽는 법)을 표시. `<rt>`로 주석 내용을, `<rp>`로 미지원 브라우저용 괄호를 감쌈.
  * **웹폼 `<form>` 확장 (실기 대비)**
      * **`GET` vs `POST`**: `GET`은 URL에 데이터 노출(가벼움), `POST`는 숨겨서 전송(보안).
      * **폼 요소 공통 속성 (⭐필수 암기)**
        | 속성 | 설명 |
        | :--- | :--- |
        | `name` | 서버로 전송될 때 데이터의 **이름** 역할. |
        | `value` | 요소의 **초기값** 또는 전송될 값. |
        | `required` | **필수 입력** 항목으로 지정. |
        | `readonly` | **읽기 전용**으로 지정 (수정 불가). |
        | `disabled` | 요소를 **비활성화** (선택/입력/전송 불가). |
      * **`<label>` 사용법 2가지**: `for` 속성으로 id를 연결하거나, 입력 요소를 감싸서 사용.
      * **`<input>` 타입 완전 정리**
        | type | 설명 | 주요 속성 |
        | :--- | :--- | :--- |
        | `text`, `password` | 한 줄 텍스트, 비밀번호 | `placeholder`, `maxlength` |
        | `radio`, `checkbox` | 단일 선택, 복수 선택 | `name`, `value`, `checked` |
        | `file` | 파일 첨부 | `accept` (파일 종류 지정) |
        | `date`, `number`, `range`| 날짜, 숫자, 슬라이더 | `min`, `max`, `step` |
        | `email`, `url`, `tel`| 이메일, 주소, 전화번호 | `required` |
        | `submit`, `reset` | **폼 제출, 초기화 버튼** | `value` (버튼 텍스트) |
        | `button` | 일반 버튼 (JS와 연동) | |
        | `hidden` | 숨겨진 데이터 | `name`, `value` |
        > 📢 **파일 업로드 `accept` 속성 예시**: `<input type="file" accept="image/*">` (모든 이미지), `<input type="file" accept=".pdf, .docx">` (특정 확장자)
      * **`<button>` vs `<input type="button">` 비교**
        | 구분 | `<button>` 태그 | `<input>` 태그 |
        | :--- | :--- | :--- |
        | **내용** | **`<img>` 태그나 텍스트 등** 자유롭게 넣을 수 있음 | `value` 속성으로 **텍스트**만 표시 |
        | **기본값** | `type` 미지정 시 **`submit`**(제출)으로 동작 | `type="button"`은 아무 동작 안 함 |
      * **선택 목록: `<select>` vs `<datalist>` (O/X 대비)**
        | 구분 | `<select>` (선택 상자) | `<datalist>` (콤보 박스) |
        | :--- | :--- | :--- |
        | **특징** | **정해진 목록에서만** 선택 | **직접 입력 + 추천 목록** 제공 |
        | **용도** | 카테고리, 년/월/일 등 | 검색창 자동 완성 |
      * **`<textarea>`**: 여러 줄 텍스트 입력 (`rows`, `cols`로 크기 지정)
          * **코드:** `<textarea rows="3" cols="20" placeholder="내용 입력"></textarea>`
