네, 알겠습니다. 1단과 중복되는 `target` 속성 설명을 제거하고, 대신 시험에 나올 확률이 높은 **폼 입력 요소의 주요 속성**에 대한 상세 설명을 추가하여 2단을 수정했습니다.

말씀하신 `[cite]` 표시도 나타나지 않도록 깨끗하게 정리했습니다.

### **[2단] HTML의 구조 (구조화 & 입력)**

#### **3️⃣ 챕터 3: 문서 구조화와 웹폼**

  * **구조화 기본 태그 & 전역 속성**
      * `<div>` vs `<span>`: `<div>`는 블록 단위(한 줄 전체)의 논리적 영역, `<span>`은 인라인 단위(글자 일부)의 작은 논리적 영역을 만든다.
      * **전역 속성**: 모든 태그에 사용할 수 있는 공통 속성.
        | 속성 | 설명 | 비고 |
        | :--- | :--- | :--- |
        | `id` | **고유 식별자** (페이지 내 유일해야 함) | CSS `#`, 북마크 목적 |
        | `class` | **그룹 식별자** (여러 번 중복 사용 가능) | CSS `.`, 스타일 그룹화 |
        | `title` | **툴팁** (마우스를 올리면 추가 정보 표시) | |
        | `style` | 요소에 CSS 스타일 직접 적용 | |
  * **시맨틱 태그 I - 페이지 전체 구조**
      * `<header>`: 머리말 | `<nav>`: 메뉴/링크 그룹 | `<main>`: 핵심 내용(페이지당 1회) | `<section>`: 주제별 구획/장(Chapter) | `<article>`: 독립된 글(기사 등) | `<aside>`: 보조 내용(광고 등) | `<footer>`: 바닥글
  * **`<iframe>` 태그 (서술형/실기 대비)**
      * **역할**: 다른 웹 페이지를 현재 문서 안에 삽입하는 창(인라인 프레임)을 만든다.
      * **주요 속성**
        | 속성 | 설명 |
        | :--- | :--- |
        | `src` | 프레임에 표시할 문서의 경로 또는 URL |
        | `srcdoc` | `src` 대신 간단한 HTML 코드를 직접 삽입 |
        | `name` | 프레임의 고유 이름 지정 (\<a\> 태그의 `target`으로 사용) |
  * **시맨틱 태그 II - 세부 콘텐츠 표현**
      * `<blockquote>`: 블록 단위의 긴 인용문. `<cite>`는 인라인 단위 인용, 출처 표시.
      * `<figure>` & `<figcaption>`: 이미지, 코드 등을 `<figure>`로 감싸고, `<figcaption>`으로 제목이나 설명을 붙인다.
      * `<details>` & `<summary>`: `<details>`로 상세 정보를 감싸고 `<summary>`로 제목을 표시하면, 접었다 폈다 할 수 있는 UI가 생성된다.
      * `<time>`: 날짜/시간 정보에 의미 부여. | `<ruby>`: 문자 위에 주석(`<rt>`) 표시.
  * **웹폼 `<form>` 확장 (실기 대비)**
      * **`<form>` 태그 주요 속성**: `action`(제출할 서버 URL), `method`(전송 방식 `get`/`post`)
      * **폼 입력 요소의 주요 속성 (⭐필수 암기)**
        | 속성 | 설명 |
        | :--- | :--- |
        | `name` | 서버로 전송될 때 데이터의 **이름** 역할. |
        | `value` | 요소의 **초기값** 또는 전송될 값. |
        | `placeholder` | 입력 예시를 보여주는 **안내 문구**. |
        | `required` | **필수 입력** 항목으로 지정. |
        | `disabled` | 요소를 **비활성화** (선택/입력 불가). |
        | `readonly` | **읽기 전용**으로 지정 (수정 불가). |
        | `checked` | `radio`, `checkbox`의 **기본 선택** 항목 지정. |
        | `maxlength`| 최대 **입력 글자 수** 제한. |
      * **`<input>` 타입 완전 정리**
        | type | 설명 | 주요 속성 |
        | :--- | :--- | :--- |
        | `text`, `password` | 한 줄 텍스트, 비밀번호 | `placeholder`, `value`, `size`, `maxlength` |
        | `search`, `url`, `email`, `tel`| 검색어, URL, 이메일, 전화번호 (형식 검증) | `required` |
        | `radio`, `checkbox` | 단일 선택(라디오), 복수 선택(체크박스) | `name`, `value`, `checked` |
        | `number`, `range` | 숫자 입력(버튼/슬라이더) | `min`, `max`, `step`, `value` |
        | `date`, `month`, `week`, `time` | 날짜, 월, 주, 시간 | `min`, `max`, `value` |
        | `file` | 파일 첨부 | `accept` (파일 종류 지정) |
        | `color` | 색상 선택 | |
        | `submit`, `reset`, `button`| 제출, 초기화, 일반 버튼 | `value` |
      * **`<button>` vs `<input type="button">`**
        | 구분 | `<button>` 태그 | `<input>` 태그 |
        | :--- | :--- | :--- |
        | **내용** | **`<img>` 태그나 텍스트 등**을 자유롭게 넣을 수 있음 | `value` 속성으로 **텍스트**만 표시 |
        | **기본값** | `type` 미지정 시 \*\*`submit`\*\*으로 동작 | `type="button"`은 아무 동작 안 함 |
      * **선택 목록: `<select>` vs `<datalist>` (O/X 대비)**
        | 구분 | `<select>` (선택 상자) | `<datalist>` (콤보 박스) |
        | :--- | :--- | :--- |
        | **특징** | **정해진 목록에서만** 선택 가능 | **직접 입력**도 가능하고, **추천 목록**도 제공 |
      * **`<textarea>`**: 여러 줄 텍스트 입력 (`rows`, `cols`로 크기 지정)
  * **진행 및 수치 표현**
    | 태그 | 설명 | 예시 |
    | :--- | :--- | :--- |
    | `<progress>` | 작업의 **진행률** (0\~100%) | 파일 업로드 진행률 |
    | `<meter>` | 정해진 범위 내의 **수치/비율** | 디스크 사용량 (80/100GB) |
