## 정리 노트

[notes/linux_command_summary.md](notes/linux_command_summary.md) 는 1,589줄짜리 문서이고 세 덩어리로 나뉘어 있습니다.

- 리눅스 기본 명령어: `ls`, `cd`, `rm`/`rmdir`, `cp`, `mv`, `cat`/`head`/`tail`/`more`/`less`, `file`, `clear`
- Bash 스크립트: shebang, 특수 변수(`$0`, `$#`, `$@` 등), `test`·`[ ]`·`[[ ]]`, 관계 연산자와 파일 검사, if/elif, case, while·until·for, `select`, break/continue, 함수와 `local`
- 가상화와 도커: 링 보호, 전 가상화와 반 가상화, Type 1/Type 2 하이퍼바이저, Xen, KVM, 컨테이너, Dockerfile 작성, 이미지·컨테이너 명령, Docker Compose
