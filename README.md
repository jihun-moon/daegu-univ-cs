## 👋 소개 (About)

본 저장소는 대학 전공 과정에서 배운 컴퓨터 과학 지식을 코드와 문서로 기록하는 \*\*'살아있는 학습 아카이브'\*\*입니다.

  - 📚 전공 과목별 실습 및 과제 코드 기록
  - RULES 통일된 폴더 구조와 커밋 규칙 적용
  - 🔗 Notion과 연동하여 개념 학습과 프로젝트 진행 상황을 버전 관리
